Clinic website: deployment notes
1. Replace https://www.example.com with the clinic's real domain in every file (find and replace).
2. Upload the folder contents to the web root of any static host (e.g. an EU-based host).
3. Register the domain in Google Search Console and Bing Webmaster Tools and submit /sitemap.xml.
4. Optionally create a Google Business Profile as a service-area business (address hidden) covering the regions you serve.
5. Optional: self-host Source Serif 4 and Source Sans 3 (SIL Open Font Licence) in /assets/fonts; the site falls back to system fonts without them and makes no third-party requests.
